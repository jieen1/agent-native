Foundry · SDLC 系统原型

人负责说清楚，系统负责做出来，并且自己证明做对了。
规划、审批、UI 评审由人主导完成；派发、开发、测试、审计、交付在编排器中全自动执行，全程证据可追溯。

S4

阶段步进条 + 执行记录时间线 + 依赖迷你图；失败路由三操作（重派 / 回退 / 升级）与交付证据一屏可达。

收件箱
S5

人被打断的唯一入口：签核、升级裁决、失败路由、通知一处处理完。判据不齐的批准按钮会告诉你缺什么。

Sprint 驾驶舱
S6

一个 sprint 从规划到交付的单页指挥部：八相位时间线、随相位切换的作战面板、产物库与签核状态。

tracker 打开
运行详情
S7

一个 run 的完整真相：真正的 DAG 图（依赖边、fanout、loop、人工门）+ 节点检查器 + attempt 时间线与证据。

orchestrator 打开
工作流库
S8

工作流即数据：九套 SDLC 模板（完整流水线 / 快速任务 / 热修 / 调研…）带 DAG 缩略图、版本链与成功率统计。
