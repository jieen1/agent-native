表面层级（四级表面模型） §2.2

L0 背景 → L1 面板（--panel/--sidebar）→ L2 卡片（--card）→ L3 浮层（+shadow）。同级不叠加；L1 与 L0 必须有可感知色差；阴影仅 L3。

状态环 StatusRing §3.1

动效 Motion §2.6

权威源 design-system/foundry-motion.html（Foundry v3 动效基建块；实证基础 multica.ai 源码级动效语言 + 本项目生产工具红线）；tokens 与曲线数值不可改，只按语义挂类/属性。下方 5 个模式均为可运行的活体演示——其 style/script 已整块内联进本文件一次（见 #foundry-motion / #foundry-motion-js）。

Token 值 用途 multica 实证出处
--fm-dur-1 120ms 微反馈：hover、图标切换 multica base.css 最短反馈档，快于注意转移阈值，hover 不显"动画感"
--fm-dur-2 240ms 小型：按钮/开关状态、Toast、菜单 multica tokens.css 的 UI 元件标准档，与菜单/toast 出现节奏一致
--fm-dur-3 400ms 中型：对话框 enter、完成打勾、区块 reveal multica 对话框类浮层 enter 阶梯，位移+透明度两段感知完整
--fm-dur-4 700ms 大型：庆祝时刻、欢迎/空状态插画 multica 大幅插画过渡上限，超过易显拖沓，已是克制上限
--fm-ambient-1 1600ms 活跃脉动 multica"活跃指示"呼吸周期，足够慢以不构成高频闪烁
--fm-ambient-2 2500ms thinking 扫光 multica 文字扫光周期，比活跃脉动更慢以区分"思考中"与"活跃中"
--fm-ambient-3 3200ms 描边光束（仅单一 CTA 级场景） multica 最慢氛围档，仅供全屏唯一焦点元素，避免多处同时争抢注意力
--fm-ease-standard cubic-bezier(0.4, 0, 0.2, 1) 一切常规过渡 multica/Material 标准曲线，加减速对称，默认无语义过渡基线
--fm-ease-enter cubic-bezier(0.16, 1, 0.3, 1) 进场从容 multica 入场曲线，前段快尾段长，呈现从容落位感
--fm-ease-exit cubic-bezier(0.7, 0, 0.84, 0) 离场干脆 multica 离场曲线，加速陡峭，避免离场拖泥带水
--fm-ease-bounce cubic-bezier(0.5, 1.5, 0.4, 1) 仅庆祝时刻 multica 唯一超出 [0,1] 区间曲线，专供一次性庆祝回弹
--fm-shift-1 4px 位移基准（hover 提升/reveal 入场） multica 位移最小档，工具型产品克制上限，避免布局抖动感
--fm-shift-2 8px 位移强档（较大区块入场） multica 位移次档，仅供低频大区块一次性入场
--fm-scale-hover 1.02 hover 放大系数 multica 悬浮缩放上限，超过即显跳动而非抬起
--fm-scale-active 0.98 按下收缩系数 multica 按下态缩放，与 hover 对称形成 press 实体感

模式 3 · 两段式完成 fm-complete
适用场景：验收通过、迁移落库等一次性"完成时刻"，不循环播放。
语义挂载：目标徽标加 class="fm-complete"（一次性）；内联 SVG 勾形还会播放描边打勾，本产品图标默认 Tabler webfont，故通常只呈现徽标回弹。
禁用场景：非"首次达成"的历史行禁止反复播放；禁用于失败态。
模式 4 · 导航扫条 fm-nav-progress
适用场景：顶部路由切换/异步加载的 pending 提示，与真实网络进度解耦。
语义挂载：<div class="fm-nav-progress"> 挂在 body 顶部（生产态 position:fixed），切换开始置 data-active="true"，完成后移除；本演示为容器内约束展示。
禁用场景：局部区块加载不用（改用骨架屏）；同一时刻只允许一条，不与其他顶部横幅共存。

适用场景：KPI/统计数字变化时的读数动画（吞吐量、tok 计数等）。
语义挂载：元素加 data-fm-count="目标值" 由运行时自动初始化；手动更新调用 window.fmCountTo(el, target)。
禁用场景：高频刷新的表格/列表数字列不用（反复跳动降低可读性），仅限展示位/KPI 卡；reduced-motion 下直接落值。
红线
高频操作面（看板/队列/表格）入场表演动效；hover 只用 --fm-dur-1/2
overflow:auto 容器内的元素使用位移类动效（只准 opacity）
拖拽/手势进行中（[data-fm-gesturing="true"]）仍带 transition
--fm-ease-bounce 回弹曲线用于 fm-complete 以外的场景
任何动效不带 prefers-reduced-motion 降级

禁则清单 §6

全局红线——任何屏、任何组件、任何原型都适用。

卡片/行左侧竖向强调色条（改用 tint + 描边 + 状态环）
卡片嵌套卡片（卡内用 divider + 眉题扁平分组）
次级面板与背景同色仅靠 1px 线（必须 --panel 表面）
emoji / 文字符号（＋ ↗ ✓ →）充当图标（一律 Tabler）
硬编码颜色（一律语义 token + color-mix）
手搓绝对定位弹层 / 浏览器 alert·confirm·prompt
L3 以外的阴影分层（卡片靠 border）
全屏 loading spinner（用骨架或乐观 UI）
自建 prompt 输入框（必须共享 composer 栈）
无降级动效（必须 prefers-reduced-motion）
