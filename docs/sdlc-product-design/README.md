design 应用中。原型清单见 [05-design-content.md](./05-design-content.md) 附录。

## 阅读顺序建议

- 想了解"这套系统是什么、怎么用"：读 00 → 02。
- 要评审交互与页面：读 01 → 03 → 04 → 05，对照原型。
- 要对照 v1.1 的流程细节（验收纪律、红线、数据模型增量）：v1.1 两份文档仍然有效，
  v2.0 引用而不重复其内容。
